01

SiftSift

HR-tech · ServerlessReact · AWS Lambda · DynamoDB · LLM API
↗

I don't trust an LLM to pick a number, so in Sift it doesn't. The model only quotes the lines in a resume that back each requirement, and plain Python turns those quotes into a score. Same resume, same score, every time. Changing the weights costs nothing because nothing goes back to the model. Names and contacts can be hidden for blind screening.

  • 1query for the top-N
  • 0extra calls to re-rank
  • −12%LLM spend

02

MLOps BenchMLOps Bench

MLOps · AWSLangGraph · FastAPI · EC2 · Next.js
↗

Runs four object detectors (YOLO26, Faster R-CNN, RF-DETR and Grounding DINO) through one LangGraph pipeline on AWS, with an LLM grading the results. The LLM turned out to be bad at maths. Its IoU was off by up to 0.11, and it gave different answers for the same boxes even at temperature 0. Now every number gets recomputed locally, and a failed run is never saved as a fake 0.0.

  • 4detectors, same images
  • 0.11IoU error caught

04

Warranty AIWarranty AI

Automotive · MLscikit-learn · Streamlit · Python
↗

My first model was way too sure of itself. It gave 100% confidence even when the complaint said one thing and the claim amount said another. I pulled it back and wrapped it in seven guardrails, so anything under 60% confidence, or without real evidence, goes to a person instead. It reads English, Hinglish ("battery backup bahut kam hai") and typos ("batery"), and the demo runs entirely in your browser.

  • 97.8%held-out accuracy
  • 65/65test cases
  • 9 msper claim
